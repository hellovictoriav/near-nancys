# Near Nancy's

Handy / Vassileva family house tracker for Martha's Vineyard. A small static site: listings, savings, house notes, and a family board.

Live: https://hellovictoriav.github.io/near-nancys/

Pages: `index.html` (home), `listings.html` (homes & land), `savings.html`, `house.html`, `board.html`. Listing data lives in `listings.json`; optional photos in `images/`.
